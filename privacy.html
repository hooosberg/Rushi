隐私政策

最后更新：2026 年 5 月 3 日 · Effective: May 3, 2026

如是（Rushi，下称"应用"或"我们"）是一款仅在 iPhone / iPad 设备本地运行的诵经、念珠、抄经与冥想应用。本政策说明应用如何处理你的数据，并对应 Apple App Store 隐私规范（Privacy Nutrition Labels）所要求披露的所有项目。

简短结论

  • 不收集任何个人身份信息、用户内容、使用数据、诊断信息或财务信息。
  • 应用不联系任何外部服务器。无网络请求、无分析 SDK、无第三方追踪、无广告网络。
  • 所有诵经进度、念珠回数、回向文字、抄经字迹、念珠搭配偏好仅保存在你的设备上。
  • 如你启用了 iCloud 同步，数据通过 Apple 提供的私人 iCloud 数据库同步，由 Apple 端到端加密；开发者无任何方式读取这些数据。

应用在你的设备上保存什么

下列数据保存在 app sandbox（应用沙盒）内，仅你本人和（如开启 iCloud 同步的话）你的 iCloud 私人数据库可访问：

项目位置
当前所选经文与阅读进度UserDefaults
念珠材质 / 形状 / 挂饰偏好UserDefaults
已完成的念珠回数与回向文字SwiftData 本地数据库
书签 / 收藏的经文段落SwiftData 本地数据库
抄经字迹（如启用了保存）app sandbox 文件目录
偏好的字体设计、字号、界面语言UserDefaults

你可以随时在 iOS 设置 → 通用 → iPhone 储存空间 → 如是 中查看占用，或卸载应用以删除全部本地数据。

iCloud 同步（可选）

如你在 iOS 系统设置中允许"如是"使用 iCloud Drive，应用会通过 Apple CloudKit 私人数据库在你自己的 iCloud 账户内同步上述数据。我们：

  • 不持有，不可读取，不可访问该 iCloud 容器中的任何内容；
  • 不通过任何方式向 Apple 之外的第三方传输该数据；
  • 同步通道由 Apple 提供端到端加密，技术细节见 Apple Platform Security 文档。

禁用 iCloud 同步：iOS 设置 → 你的 Apple ID → iCloud → iCloud Drive → 关闭"如是"。

第三方服务与 SDK

应用不集成任何第三方分析、广告、崩溃报告、身份验证或社交登录 SDK。整个应用仅依赖以下 Apple 系统框架：SwiftUI、UIKit、SwiftData、CloudKit、Foundation、CoreText、CoreMotion（用于挂饰摆动手感）。

开源经文

应用内显示的金刚经、心经及其多语种译本，全部出自公有领域底本（古译者圆寂超过百年；20 世纪初印本超过 95 年版权保护期）。整理后的 Markdown 版本以 CC0 1.0 公开发布在 GitHub 仓库。

应用内捆绑了 Noto Serif CJK SC / TC 字体子集（SIL Open Font License 1.1），以保证在任何 iOS 设备上都能呈现完整的中文衬线渲染。LICENSE 文件随 app 一并捆绑（位于 app bundle 的 Fonts/OFL-LICENSE.txt）。

儿童隐私

应用未面向 13 岁以下儿童设计，亦不针对儿童收集任何信息（实际上对任何用户都不收集任何信息）。应用内容（佛教经文）适合一般受众，无暴力、色情或不当内容。

美国加州 / 欧洲 GDPR / 中国《个人信息保护法》

由于应用不收集任何个人信息，前述法规对"个人信息处理者"的实质性义务——目的告知、同意取得、数据可携、删除请求、跨境传输登记——在本应用中均不发生。如你居住在上述法域并仍希望行使知情或申诉权利，请通过下方联系方式与我们沟通。

变更

如本政策有任何变更（例如未来加入了任何形式的数据收集），我们会：（1）更新本页面顶部的"最后更新"日期；（2）在 GitHub 仓库的 privacy.html 提交记录中保留完整变更历史；（3）在 app 内通过显著提示告知你，并请求重新同意。
